## Marches à suivre pour lancer le projet

**Étape 1 :** copier le '.env.development' de backend et le renommer '.env' dans backend, puis copier ce même ".env" à la racine du projet\
**Étape 2 :** cmd "make composer-install" dans "backend"\
**Étape 3 :** cmd "make" à la racine\
**Étape 4 :** cmd "make migrate-fresh-seed" à la racine
